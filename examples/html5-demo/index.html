FastPix Video Data — HTML5 demos

No bundler. Run npm run build in the repo root once (to produce dist/index.js), then serve the repo root (these pages load ../../dist/index.js), e.g.:

npx serve .   # from repo root, then open /examples/html5-demo/
  • native-hls.html — plain <video>, no library (Safari/iOS)
  • hls.html — hls.js (cross-browser)
  • dash.html — dash.js (DASH has no native path)
